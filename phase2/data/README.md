# Data

Nothing in this directory contains patient-level information. Raw and processed
EHR data are **never** committed (`data/raw/`, `data/processed/` are git-ignored);
they are rebuilt locally from your own credentialed download with the scripts
described below.

```
data/
├── README.md                 <- this file
├── mappings/                 <- small, shippable, non-patient side information
│   ├── drug_name_to_pubchem.json          normalised MIMIC drug name -> {PubChem CID, SMILES}
│   ├── twosides_pairs_top40.csv           interacting PubChem CID pairs (TWOSIDES, 40 most frequent side effects)
│   └── twosides_pairs_top40_side_effects.csv  the 40 side-effect types kept and their row counts
├── raw/        (git-ignored) <- MIMIC-III CSVs / TWOSIDES CSV, or junctions to them (scripts/link_local_data.ps1)
└── processed/  (git-ignored) <- output of preprocess_mimic.py + build_hetero_graph.py
        └── <name>/records.pkl, voc.json, stats.json, drug_raw_names.json, graph.pt, graph_stats.json
```

## 1. MIMIC-III v1.4 (required for the real experiments)

MIMIC-III is distributed by PhysioNet under a credentialed Data Use Agreement and
**must not be redistributed**. To obtain it:

1. Create a PhysioNet account and complete the CITI "Data or Specimens Only Research" course.
2. Apply for credentialed access and sign the DUA for
   <https://physionet.org/content/mimiciii/1.4/>.
3. Download at least these tables (CSV or CSV.GZ; nested `TABLE.csv/TABLE.csv` layouts are accepted):

   | table | used for | required |
   |---|---|---|
   | `PRESCRIPTIONS` | drug labels (MAIN drug type; free-text `DRUG` names are normalised) | yes |
   | `DIAGNOSES_ICD` | diagnosis nodes / visit features (ICD-9) | yes |
   | `PROCEDURES_ICD` | procedure nodes (ICD-9) - preferred | optional |
   | `PROCEDUREEVENTS_MV` | procedure nodes (MetaVision item ids) - fallback when `PROCEDURES_ICD` is absent | optional |
   | `ADMISSIONS` | chronological ordering of admissions (falls back to first prescription date) | optional |

4. Point the pipeline at the folder:

   ```powershell
   powershell -File scripts/link_local_data.ps1 -MimicDir "D:\path\to\mimic-iii-clinical-database-1.4"
   python scripts/preprocess_mimic.py --mimic_dir data/raw/mimic-iii --out data/processed/mimic3
   ```

   or simply pass `--mimic_dir <absolute path>` directly.

The preprocessing keeps `SUBJECT_ID` inside `data/processed/*/records.pkl` only so
that the deterministic patient-level split can be computed by hashing
(`src/hgdr/data/splits.py`); that file is git-ignored and never leaves your machine.

## 2. MIMIC-III Clinical Database Demo v1.4 (for the smoke test)

100 patients, openly available under the ODbL 1.0 licence:
<https://physionet.org/content/mimiciii-demo/1.4/>.
`scripts/demo_mode.ps1` downloads and unpacks it into `data/raw/mimic-iii-demo/`
automatically. Results on the demo are only a pipeline check; they are not
scientifically meaningful.

## 3. TWOSIDES (drug-drug interactions)

The shipped `mappings/twosides_pairs_top40.csv` was derived from the TWOSIDES
release (Tatonetti et al., *Sci. Transl. Med.* 2012; nSides/OffSIDES 2.x,
<https://nsides.io> or <https://tatonettilab.org/offsides/>). It lists unordered
PubChem-CID pairs that co-occur with at least one of the 40 most frequently
reported side effects. To rebuild it (or use a different `--top_k`) download
`TWOSIDES.csv.gz` and run

```powershell
python scripts/build_ddi_graph.py --twosides path\to\TWOSIDES.csv --top_k 40
```

(The 660 MB source file is read in chunks; only the CID / condition columns are loaded.)

## 4. PubChem (drug -> CID -> SMILES)

`mappings/drug_name_to_pubchem.json` maps normalised MIMIC drug names to PubChem
CIDs and canonical SMILES. It merges two legacy dictionaries from the research
code and was extended with the PubChem PUG-REST API for the full-MIMIC vocabulary.
Unmapped names (mostly fluids, vaccines, multi-ingredient products, biologics)
receive no molecular graph and no DDI edges but are still recommended via their
learned ID embedding. To extend the mapping for a new vocabulary:

```powershell
python scripts/build_drug_mapping.py --processed_dir data/processed/mimic3 --online
```

## What is *not* here (and why)

The original research folder contained `records_patient*.pkl`, `filtered_data.csv`,
`merged_data_all*.csv`, `processed_patient_data_sampled.csv`, `preprocessed_dataset.pkl.gz`,
`ehr_hetero_graph.*`, `hetero_graph.bin`, `patient_drug_graph.bin`,
`patient_recommendation_table*.csv`, `train/val/test_pairs.csv` and model checkpoints.
All of these are derived from credentialed MIMIC-III at the patient/admission level
(or are > 50 MB) and were therefore deliberately excluded. Every one of them is
regenerated by the scripts in `scripts/`.
